2. Dataset and Data Quality

Columns: Train_No, Train_Name, Source_Station_Name, Destination_Station_Name, and days. The original input has no missing values in the five supplied columns. Exact duplicate rows were checked; 0 were found. Text fields were trimmed and train/station names standardized to uppercase. The raw day value is preserved in days_raw.

Data interpretation note: The day field contains values such as Saturday and Saturdayd. The trailing “d” was removed only for the normalized Operating_Day analysis and is retained in the raw field with a boolean flag. Its business meaning was not assumed.

8. Key Findings

  • The dataset contains 11,113 rows and 5 columns before cleaning.
  • There are 921 unique source stations and 924 unique destination stations.
  • CST-MUMBAI is the most frequently recorded source station (513 records); CST-MUMBAI is the most frequently recorded destination station (514 records).
  • Friday has the highest normalized day count (1,649); Monday has the lowest (1,503).
  • Normalized day categories contain 7,918 weekday records and 3,195 weekend records.
  • The raw day field includes 1,153 records whose value ends in 'd'. This suffix was preserved in days_raw and flagged separately; its exact business meaning should be confirmed with the dataset owner.
  • The average-trains-per-day column is calculated as each source station's row count divided by seven. It is a simple normalized average, not a timetable-level estimate, because the source data is a list of train records rather than daily service counts for every calendar date.

9. Recommendations

  • Confirm the meaning of the trailing 'd' in day values before using it for operational decisions; the raw value is retained in days_raw and Daily_Flag_Suffix_d.
  • Use the cleaned Operating_Day column for day-wise charts and filters so values such as 'Saturday' and 'Saturdayd' are grouped under Saturday while preserving the original value.
  • Review high-volume source and destination stations for staffing, platform planning, and timetable validation; treat record counts as dataset frequency rather than real-time passenger demand.
  • For a stronger day-of-week correlation analysis, obtain dated service records or an explicit one-hot operating calendar. A single categorical operating-day field supports distribution comparisons, but not a meaningful causal correlation claim by itself.
